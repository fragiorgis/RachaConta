# RachaConta

App para dividir uma conta entre amigos e marcar quem já pagou. Feito em Kotlin com telas XML para a parcial de Programação Mobile 1.

## Como rodar

1. Abra a pasta do projeto no Android Studio.
2. Instale o Android SDK 37 pelo SDK Manager e use JDK 25 no Gradle.
3. Aguarde a sincronização e execute o módulo `app` em um emulador com Android 13 (API 33) ou superior.

## Bibliotecas

- AndroidX Core, Activity e AppCompat: suporte às telas e integração com o Android.
- Material Components: campos, botões e checkboxes.
- RecyclerView: lista com o valor e o pagamento de cada pessoa.
- JUnit e AndroidX Test/Espresso: testes do cálculo e das telas.
- Foojay Toolchain Resolver: obtenção do JDK usado pelo Gradle.
